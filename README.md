# zapret-unified

Автор: **pronsik**

Настольное приложение для Windows (Tauri: Rust + Svelte), которое собирает в одном окне
три инструмента: VPN-клиент, обход DPI-блокировок и локальный прокси для Telegram.

## Возможности

- **VPN.** Ссылки `vless://`, `vmess://`, `trojan://`, `ss://`, подписки (с трафиком, сроком и
  автообновлением) и xray-JSON. Добавление по кнопке, вставке из буфера или QR-коду с фото.
  Журнал подключения, пинг серверов, профили маршрутизации.
- **Режимы VPN.**
  - `proxy`: xray SOCKS/HTTP и системный прокси Windows. Лёгкий режим.
  - `xray tun`: TUN-вход Xray (весь трафик системы).
  - `sing-box tun`: TUN на sing-box с `auto_route` и `strict_route`, DNS через прокси.
  - `tun2proxy`: xray плюс tun2proxy.
  - `adaptive tun`: собственная политика маршрутизации поверх sing-box. При подключении
    проверяет, что открывается напрямую, и гонит через прокси только остальное.
- **Обход блокировок (zapret).** Запуск `winws.exe` по стратегиям из `general*.bat`,
  проверка стратегий, редактор списков доменов и IP с проверкой записей, закрепление файлов
  от перезаписи обновлениями, «Remove Services» (остановка процессов и выгрузка драйвера WinDivert).
- **Telegram-прокси.** tg-ws-proxy-rs: порт, секрет, способы подключения, командная строка
  предпросмотром, ссылка `tg://proxy` в один клик.
- **Интерфейс.** Светлая и тёмная тема (или как в системе), цвет и фоновое фото, русский
  и английский языки, скруглённые углы окна, работа в фоне через значок в трее.

## Требования

- Windows 10 или 11, 64-бит.
- Права администратора (драйвер WinDivert и TUN-адаптеры требуют их; приложение запрашивает UAC).
- WebView2 Runtime (обычно уже установлен в Windows 10/11).

## Компоненты и источники

Приложение не содержит внешних исполняемых файлов в архиве: при первом запуске и по
необходимости оно скачивает их из официальных релизов.

| Компонент | Для чего | Источник |
|---|---|---|
| zapret-discord-youtube (стратегии, `winws.exe`, WinDivert) | обход DPI | https://github.com/Flowseal/zapret-discord-youtube |
| tg-ws-proxy-rs | прокси для Telegram | https://github.com/valnesfjord/tg-ws-proxy-rs |
| Xray-core | VPN-ядро | https://github.com/XTLS/Xray-core |
| sing-box | TUN-режимы | https://github.com/SagerNet/sing-box |
| tun2proxy | режим tun2proxy | https://github.com/tun2proxy/tun2proxy |
| wintun | драйвер виртуального адаптера | https://www.wintun.net |

Лицензии компонентов отличаются от лицензии этого проекта. Перед распространением
собранного установщика проверьте условия каждого из них в их репозиториях.

## Безопасность и ответственность

- Конфигурация (ссылки серверов, подписки, секреты прокси) хранится локально в
  пользовательской папке приложения. Не передавайте файлы конфигурации третьим лицам:
  в них лежат учётные данные ваших серверов.
- Драйвер WinDivert и TUN-адаптеры работают на уровне системы. Используйте приложение
  только на своих устройствах и в рамках законодательства вашей страны.

## Ограничения

- Только Windows.
- В режимах на sing-box счётчики трафика недоступны (статистика есть у xray-режима).
- Правила `geoip:`, `geosite:` и `regexp:` в режимах на sing-box не применяются:
  встроенных баз там нет.
- Не все комбинации транспортов и протоколов проверены на реальных серверах.
